# 📊 Data Analysis Portfolio

Портфолио проектов по анализу данных, демонстрирующее навыки полного цикла исследования: от предобработки «сырых» данных и EDA до проверки гипотез и визуализации бизнес-метрик.

---

## 🛠 Стек технологий и инструментов
* **Языки и библиотеки:** Python (Pandas, NumPy, Matplotlib, Seaborn, SciPy)
* **Анализ данных:** Исследовательский анализ (EDA), предобработка данных, когортный анализ, продуктовые метрики
* **Статистика:** Проверка статистических гипотез (t-test, U-критерий Манна-Уитни), A/B-тестирование
* **Инструменты:** Jupyter Notebook, Git, GitHub

---

## 🚀 Проекты в портфолио

### 1. [Анализ продаж и пользовательской активности Яндекс Афиши](yandex_afisha_analysis.ipynb)
* **Цель:** Оценить динамику продаж за период, выявить ключевые паттерны поведения пользователей и проверить гипотезы для оптимизации маркетингового бюджета.
* **Что сделано:** 
  * Проведена предобработка данных и исследовательский анализ (EDA).
  * Рассчитаны ключевые продуктовые метрики (LTV, CAC, Retention Rate).
  * Построены графики распределения активности пользователей с помощью Matplotlib и Seaborn.
* **Используемый стек:** Python, Pandas, Matplotlib, Seaborn, SciPy

### 2. [Исследование рынка стартапов](startup_research/)
* **Цель:** Проанализировать факторы, влияющие на успешность и инвестиционную привлекательность стартапов.
* **Что сделано:**
  * Очищены и объединены разрозненные датасеты.
  * Выделены ключевые категории и тренды на венчурном рынке.
* **Используемый стек:** Python, Pandas, NumPy

### 3. [Анализ игровых данных «Secrets of the Dark Forest»](Secrets_of_the_Dark_Forest/)
* **Цель:** Исследовать поведение игроков внутри проекта для поиска точек роста вовлеченности.
* **Что сделано:**
  * Изучена игровая статистика и активность пользователей.
  * Сформированы выводы для продуктовой команды.
* **Используемый стек:** Python, Pandas
