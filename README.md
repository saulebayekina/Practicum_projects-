# Проекты в Яндекс Практикуме

Репозиторий содержит учебные проекты, выполненные в рамках курса по анализу данных.

## Структура репозитория

* [startup_research](./startup_research) — Исследование рынка стартапов.
* [Secrets of the Dark Forest](./Secrets%20of%20the%20Dark%20Forest) — Анализ данных проекта «Secrets of the Dark Forest».
* [Афиша Яндекс](./Афиша%20Яндекс.ipynb) — Анализ продаж билетов и поведения пользователей Яндекс Афиши.

### Список проектов:
1. Исследование стартапов
   * Цель: Анализ рынка и определение факторов успешности стартапов.
   * Библиотеки: pandas, matplotlib, seaborn, numpy.
2. Secrets of the Dark Forest
   * Цель: Анализ игровых/пользовательских данных проекта.
   * Библиотеки: Python, pandas.
3. Анализ продаж билетов Яндекс Афиши
   * Цель: Оценить динамику продаж осенью 2024, найти лидирующие регионы и партнёров, проверить гипотезы об активности пользователей mobile и desktop.
   * Библиотеки: Python, pandas, matplotlib, seaborn, scipy.
